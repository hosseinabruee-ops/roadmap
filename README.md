# Roadmap

## هدف پروژه
این ریپو مسیر یادگیری هفتگی من به‌سمت مهندسی ارزیابی و اطمینان هوش مصنوعی است.
هدف: تمرین برنامه‌نویسی، مستندسازی، و نگه‌داری تاریخچه‌ی تمرین‌ها با Git.

## ساختار پوشه‌ها
- `notes/` — یادداشت‌ها و cheat-sheet ها
- `scripts/` — اسکریپت‌های تمرینی
- `weeks/` — گزارش‌های هفتگی (W001.md، W002.md، W003.md و ...)
- `sandbox/` — پوشه‌ی آزمایش (در `.gitignore` است و commit نمی‌شود)
- `hello.py` — اولین اسکریپت پایتون
- `ideas.md` — ایده‌های جدید
- `README.md` — همین فایل
- `.gitignore` — فایل‌های نادیده‌گرفته‌شده

## درباره‌ی من
من حسین هستم و این ریپو را برای یادگیری هفتگی برنامه‌نویسی و هوش مصنوعی می‌نویسم.
